# 2027 세계일주 — 41일의 지구 한 바퀴

가족 세계일주(2027.12.8 → 2028.1.16, 동행 40일) 동선을 3D 지구본 위에 그린 인터랙티브 지도.

- 왼쪽 패널에서 도시를 누르면 지구본이 그 도시로 날아가고 상세 카드가 열립니다.
- 청록 호 = 항공, 금색 호 = 렌터카·기차.
- 단일 `index.html` — [globe.gl](https://github.com/vasturiano/globe.gl) (Three.js) CDN 사용, 빌드 불필요.

로컬 실행: `python3 -m http.server` 후 http://localhost:8000
